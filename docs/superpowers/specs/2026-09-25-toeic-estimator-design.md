日付: 2026-09-25
状態: 自律セッションで作成(ユーザー承認は事後レビュー)

## 目的

約10分のブラウザ内テストで、TOEIC L&R の予想スコアを**確率分布**として提示する
静的サイト。GitHub Pages (`https://shuheilocale.github.io/toeic-score-estimator/`)
で公開する。

- 対象: 自分のTOEICレベルをざっくり知りたい日本語話者の学習者
- 成功条件: スマホ/PCのブラウザだけで完結し、10分で「だいたいこの帯」という
  信用区間つきの推定が返ること

## 要件(ユーザー指定)

1. GitHub Pages で公開できること(= 静的サイト、ビルド不要が望ましい)
2. 約10分で終わるテスト
3. 予測はピンポイントの点数ではなく確率分布(信頼区間的な幅)で示す
4. Listening / Reading の両セクションを含む

## アーキテクチャ

**純粋な静的サイト**。HTML + CSS + vanilla JS (ES modules)。ビルドステップなし。
数理コア(IRT・スコアリング)はブラウザ/Node両対応のESモジュールにし、
`node --test` でユニットテストする。

```
toeic-score-estimator/
  index.html            # SPA(画面はJSで切替)
  css/style.css
  js/
    main.js             # 画面フロー(start → listening → reading → result)
    items.js            # アイテムバンク(L:20問, R:30問, IRTパラメータ付き)
    irt.js              # 3PL確率・Fisher情報量・θ事後分布(グリッドEAP)
    scoring.js          # θ事後 → スコア分布変換、L+R畳み込み、分位点
    chart.js            # 結果の密度曲線SVG描画
    tts.js              # Web Speech API ラッパー(リスニング音声)
  test/                 # node --test で実行
  package.json          # {"type":"module"} とテストスクリプトのみ
```

## テスト設計(出題エンジン)

- **適応型テスト(CAT)+ 項目反応理論(3PLモデル、当て推量 c=0.25 固定)**
  - 回答するたびに θ の事後分布(事前 N(0,1)、グリッド [-4,4])を更新
  - 次の問題は「現在のθ推定(EAP)で Fisher情報量が最大の未出題項目」を選択
  - 初問は中よりやや易しい項目(b≈-0.5)から開始
- **Listening: 8問 / 制限4分**。Web Speech API(speechSynthesis, en-US)で
  短い発話・会話を読み上げ、設問に4択で回答。再生は初回自動+再再生1回まで。
  TTS非対応環境ではスクリプト表示にフォールバック(その旨を結果に注記)。
- **Reading: 12問 / 制限6分**。Part5型の短文穴埋め中心+短い読解。4択。
- 時間切れは未回答のまま終了。未回答分は推定に使わない(回答数が少ないほど
  分布が広がる=不確実性が正直に出る)。

## スコアリング

- θ_L と θ_R を独立にベイズ推定(グリッド上の事後分布)
- スコア変換(線形+クランプ、5点刻み):
  - Listening: `score = clamp(round5(300 + 90·θ), 5, 495)`
  - Reading:   `score = clamp(round5(270 + 90·θ), 5, 495)`
  - 係数は公開されている受験者平均(L≈300, R≈250–270)と分布幅からの近似。
    項目パラメータは実測校正ではないため「簡易推定」と明記する。
- 合計スコア分布 = L事後 × R事後 の畳み込み(独立仮定)
- 表示: 合計スコアの確率密度曲線 + **80%信用区間**の帯 + 中央値、
  L/R各セクションの中央値と80%区間

## UI(画面フロー)

1. **スタート画面**: テスト概要(所要時間・構成)、音声チェックボタン、開始
2. **Listening**: 進捗・残り時間、音声再生UI、4択
3. **Reading**: 進捗・残り時間、問題文、4択
4. **結果**: 分布チャート(SVG)、中央値と80%区間、L/R内訳、全問レビュー
   (自分の答え・正解・スクリプト)、再挑戦ボタン

日本語UI。免責: ETS非公式・簡易推定であることをフッターと結果画面に明記。
"TOEIC is a registered trademark of ETS" の注記を入れる。

## エラー処理

- speechSynthesis 不在/失敗 → リスニングをスクリプト読解モードに切替(注記付き)
- タイマー切れ → そのセクションを即終了し次へ
- 回答ゼロのセクション → そのセクションは「推定不能(全レンジ)」として
  事前分布のまま表示

## テスト方針

- `node --test`: irt.js(3PL確率、情報量、事後更新の性質)、scoring.js
  (スコア変換の単調性・クランプ、畳み込みの正規化、分位点)
- 手動/ブラウザ: ローカルサーバで起動し、全フロー通し・TTSフォールバックを確認
